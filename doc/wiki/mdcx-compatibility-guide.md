# MDCX 兼容使用说明

`MDCX 抓取`用于接入 MDCX 抓取输出的影片目录。Jvedio 导入已有资料到自己的数据库供浏览和管理，但不接管原目录。

## 支持的目录

为最上层的扫描根选择`MDCX 抓取`。当前支持以下两种组织；两种形态不需要分别设置，演员目录只是外部工具的分类层。

```text
主形态：盘符根或输出根
<扫描根>/
  <演员目录>/
    <VID + 演员名>/
      <影片>.mp4
      <影片>.nfo
      <VID>-poster.jpg
      <VID>-thumb.jpg
      <VID>-fanart.jpg
      behind the scenes/
      extrafanart/

第二形态：影片目录直接位于扫描根下
<扫描根>/
  <VID + 演员名>/
    <影片>.mp4
    <影片>.nfo
    <本地图片和资源目录>
```

- 请选择盘符根、MDCX 输出根或直接包含影片目录的上层，不要把某一部影片目录当成整套库的扫描根。
- `backdrops`、`behind the scenes`、`extrafanart`、`extrafanart_copy`、`trailers` 是资源目录，会在发现影片前跳过，不会生成影片卡。
- 演员关系只读取影片同目录 NFO 的 `<actor><name>`；不会根据演员父目录或`VID + 演员名`目录猜测。
- 目录预检可提示“建议使用 MDCX 抓取”，但不会自动切换来源类型。不同来源类型的扫描根不能重叠。

## 按钮与结果

| 位置或按钮 | 何时使用 | 对 MDCX 抓取目录的行为 |
| --- | --- | --- |
| 新建/编辑媒体库中的`目录来源类型` | 第一次接入，或修改某个扫描根 | 为该目录选择`MDCX 抓取`并保存策略；保存只改 Jvedio 配置，不扫描、不改文件。 |
| `扫描` | 第一次接入，或 MDCX 新增影片、修改 NFO/本地图片后 | 读取新增或 NFO 内容变化的影片，将资料导入 SQLite；不移动、改名、删除、创建或覆盖目录文件。 |
| `抓取元数据` | NFO 缺少资料，且影片有明确、无冲突的标准 VID | 可选地向 MetaTube 查询并补 Jvedio 数据库；保留已有 NFO 内容与演员关系，不写 NFO、不下载或替换图片。 |
| `保存演员` | 需要在 Jvedio 手工调整某部影片的演员关系 | 只保存 Jvedio 数据库，返回“不更新 NFO”；之后扫描不会用 NFO 覆盖这部影片手工保存的演员关系。 |
| `重新拉取演员信息` / `编辑演员信息` | 需要头像、别名或演员档案 | 只更新 Jvedio 演员资料和缓存，不改影片 NFO、图片或目录。 |
| `导出用户数据` | 备份或迁移 Jvedio | 导出目录来源配置、已导入资料、演员关系、标签/评分/收藏和 Jvedio 缓存；不打包外部影片、NFO、海报、剧照或资源目录。 |
| `导入用户数据` | 在另一台电脑恢复 Jvedio 数据 | 恢复 Jvedio 用户数据；原目录必须仍可访问。路径变化后，在库管理中改为新路径再点击`扫描`；不会复制外部文件。 |

`扫描`是接入和同步入口；`抓取元数据`不是必经步骤。只浏览、搜索、查看详情/演员页或重启应用，都只读取已导入的 SQLite 数据，不会重新解析 NFO。

## 导入内容与只读边界

- **会导入**：首次`扫描`或 NFO 变化后，将 NFO 的影片资料、演员关系和同目录本地图片写入 Jvedio SQLite；原始 NFO 和图片继续留在原路径。
- **何时同步**：列表、搜索、详情和演员页只读取已导入数据。MDCX 新增影片或修改 NFO 后，请再次点击`扫描`；无效或删除的 NFO 保留最后一次成功导入的资料。
- **不会做**：不重写、生成或删除 NFO，不下载或替换图片，不移动、重命名、合并或删除影片和资源目录，也不会自动切换目录来源类型。

MDCX NFO 的 `<genre>` 与 `<tag>` 都会显示为影片“类型”，相同文本只显示一次；NFO 不会再创建“自定义”标签。自定义标签、个人评分和收藏始终属于 Jvedio 用户数据，不由 NFO 覆盖。升级后，Jvedio 会自动把历史由 MDCX 导入的自定义标签调整为类型，不需要重新扫描，也不会修改 NFO 或影片文件。

文件名标准 VID 与 NFO `num` 冲突，或只有 NFO 而没有标准 VID 时，仍可导入本地资料，但不会猜测远端身份或自动请求 MetaTube。

需要由 Jvedio 重新整理和写入 sidecar 的目录，请明确配置为`MetaTube 抓取`；切换来源类型本身不会搬迁文件。

## 迁移提醒

用户数据导入目前恢复整份 Jvedio 用户数据，不支持按媒体库选择性合并。备份 ZIP 不含外部媒体文件，因此迁移前应分别备份 MDCX 原目录；恢复后让目录按原路径可访问，或在库管理中更新路径后重新扫描。
