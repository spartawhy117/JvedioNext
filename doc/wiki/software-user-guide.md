# JvedioNext 功能 Wiki

本文面向最终用户，说明 `JvedioNext` 的主要功能、页面用途、两类媒体库差异、常用操作和设置项。更细的标准库命名边界请继续查看根目录的 `standard-library-naming-rules.md`。

## 软件定位

`JvedioNext` 是 Windows 桌面端离线影片管理工具，重点解决本地资源越来越多以后如何整理、补资料、查缺口、维护演员和标签、迁移用户数据。

它不是在线播放站，也不内置影片资源。影片、`.strm` 文件、播放器、`MetaTube` 服务地址和远程搜索来源都需要用户自行准备。

## 首次使用准备

首次启动前建议先确认三类依赖：

| 依赖 | 是否必需 | 用途 |
| --- | --- | --- |
| `.NET 8 ASP.NET Core Runtime` 与 `.NET 8 Desktop Runtime` | 必需 | 启动本地 Worker，负责扫描、抓取、数据库和后台任务 |
| `MetaTube` 服务地址 | 标准库抓取需要 | 抓取影片详情、海报、演员和标准库补资源 |
| `FFmpeg` | 本地库动态封面需要 | 为非标准本地库生成静态封面和 `preview.mp4` |

如果应用提示 Worker 启动失败，优先到 `设置 -> 诊断` 查看 `.NET Runtime` 和 Worker 状态。

## 两类媒体库

新建或编辑媒体库时，需要选择元数据来源。当前主要分为两类：`使用 MetaTube 搜刮` 和 `本地库（不搜刮）`。

| 对比项 | 标准库（MetaTube） | 本地库（不搜刮） |
| --- | --- | --- |
| 适合内容 | 规范番号影片、规范命名 `.strm` | 从论坛或社区下载的国产、OF 等非标准 JAV 电影数据，适合自己做分类和标签管理 |
| 是否需要 MetaTube | 需要，抓取和补资料依赖它 | 不需要 |
| 扫描行为 | 识别 `VID`，可整理到标准库目录结构 | 只同步文件，不移动、不重命名、不建 `VID` 目录 |
| 展示方式 | 海报卡进入影片详情页 | 合集入口和影片卡浏览，本地影片点击后直接播放 |
| 资源生成 | 抓取 `NFO / poster / thumb / fanart` | 通过 FFmpeg 生成静态封面和悬停预览 |
| 标签能力 | 支持系统标签和自定义标签 | 支持自定义标签 |

### 标准库怎么用

标准库适合已经按番号命名，或准备按标准规则整理的影片。

典型流程：

1. 在 `库管理` 点击 `新建媒体库`。
2. 选择 `使用 MetaTube 搜刮`。
3. 添加一个或多个扫描目录。
4. 保存后点击 `扫描`。
5. 扫描完成后点击 `抓取元数据`。
6. 进入单库页面浏览影片，必要时进入 `库健康` 修复缺资源或规则问题。

标准库扫描会尝试识别文件名中的 `VID`。规范单文件、合法多子集和规范 `.strm` 可以进入标准库链路；命名不合规的文件会进入规则问题报告，不会被当成有效标准影片直接抓取。

标准库多子集影片会在列表中显示为一张主卡，卡片上显示 `N Parts`，详情页中再选择具体 `Part` 播放。

### 本地库怎么用

本地库适合从论坛或社区下载的国产、OF 等非标准 JAV 电影数据。这类资源通常没有稳定番号、没有可直接搜刮的标准元数据，用户更需要保留原目录结构，并按自己的分类、合集和自定义标签进行管理。

典型流程：

1. 在 `库管理` 点击 `新建媒体库`。
2. 选择 `本地库（不搜刮）`。
3. 添加扫描目录。
4. 按需配置合集目录列表。
5. 保存后点击 `刷新目录`。
6. 如需封面和悬停预览，配置 FFmpeg 后点击 `生成动态封面`。

本地库的 `刷新目录` 是同步，不是整理。它不会移动原文件、不会重命名、不会按 `VID` 建目录，也不会因为目录名像番号就改造成标准库结构。

合集目录列表只影响软件内展示：命中的目录会显示为合集入口，用户可以继续进入合集或子合集；真实磁盘目录不会被改造。

### `.strm` 支持

`.strm` 当前只适用于标准库。

最小规则：

- 文件名必须符合标准库命名规则，例如 `ABC-123.strm`、`ABC-123_2.strm`、`FC2-PPV-4880000.strm`。
- 文件内容建议只保留一个绝对 `http / https` 播放地址。
- 不支持用 `.strm` 包装本地路径、相对路径、NAS 路径或非 `http / https` 协议。

符合规则的 `.strm` 会像普通标准库影片一样进入扫描、海报墙、详情页和随机选片链路。最终能否播放取决于播放器是否支持直接打开远程 URL。

## 页面总览

左侧导航提供固定入口：`设置`、`库管理`、`喜欢`、`演员`、`标签`，下方 `影视库` 区会列出已创建的媒体库。点击媒体库名称可进入对应单库内容页。

### 库管理

`库管理` 是媒体库管理首页，不展示影片列表，主要处理库级动作：

- 新建媒体库。
- 点击库名进入单库内容页。
- 标准库执行 `扫描`、`抓取元数据`。
- 本地库执行 `刷新目录`、`生成动态封面`。
- 编辑库名、扫描目录和合集规则。
- 移除库或删除库和库内影片。
- 进入 `查看健康`。

`移除库` 只移除软件内引用；删除类动作会进入确认流程。涉及原影片文件的危险操作需要看清弹窗说明后再确认。

### 单库内容页

单库内容页用于浏览某一个媒体库中的内容。

标准库中，影片以统一海报卡展示，点击进入 `影片详情`。列表支持搜索、排序、个人评分筛选、随机选片、批量选择、缺资料筛选和库健康入口。

本地库中，页面可能同时展示 `合集入口` 和 `影片`。点击合集进入下一层；点击本地影片直接调用播放器播放。进入某个合集后，可以使用 `当前目录加标签` 为当前目录范围内的影片追加同一个自定义标签。

批量模式下，点击卡片会切换选中状态，不再进入详情、播放或下钻合集。批量动作统一出现在顶部批量工具条。

### 库健康

`库健康` 用来判断单个媒体库是否完整、可信、可维护。

标准库重点查看：

- 抓取状态。
- `NFO / poster / thumb / fanart` 资源缺口。
- 文件规则问题。
- 失效记录。
- 分组一致性。

本地库重点查看：

- 静态封面是否缺失。
- `preview.mp4` 是否缺失。
- 文件与索引摘要。
- 结构一致性。

健康页不会因为打开页面就自动扫描、抓取或清理。`刷新健康状态` 只刷新统计；`一键重抓并补资源`、`一键修复封面与预览`、`重新检查失效记录` 才会触发对应后台动作。

### 影片详情

影片详情页展示单部影片的完整信息。

主要能力：

- 查看标题、主图、`VID`、发布日期、时长、导演和 sidecar 状态。
- 播放影片或选择多子集 `Part` 播放。
- 设置或清除个人五星评分。
- 收藏影片。
- 重新抓取当前影片元数据。
- 查看清晰图片。
- 打开所在文件夹。
- 查看演员，进入演员详情。
- 查看 `类型 / 系列 / 厂商 / 自定义标签`。
- 编辑自定义标签。
- 从演员或标签右键跳转到搜索页。

从列表进入详情时，如果来源列表提供上下文，详情页会显示上一部和下一部按钮，只在当前来源页序列内切换。

### 搜索

搜索页用于远端搜索和本地状态核实，不是页内详情浏览器。

支持三种模式：

- 单个 `VID`。
- 单个演员原词。
- 单个 `Tag` 原词。

搜索结果会显示远端影片卡，并回填本地状态，例如标准库已存在、未入库等。标准库已存在的结果可以直接触发 `补抓已有影片`；所有结果都可以打开来源页或更多来源。

演员和标签搜索建议使用日文原词或站点原词。演员页、标签页、收藏演员、收藏标签和影片详情页的右键菜单都可以带着上下文跳入搜索页，并自动搜索。

### 演员

演员页是跨库演员聚合入口。

主要能力：

- 搜索演员。
- 按名称或作品数排序。
- 按作品数量、头像状态、年龄、身高、罩杯筛选。
- 批量收藏或批量取消收藏。
- 批量补全演员扩展信息。
- 右键演员搜索相关影片。
- 进入演员详情页。

演员扩展信息当前包含生日、年龄、身高和罩杯。批量补全运行时，页面会显示已补全、未补全和当前进度。

### 演员详情

演员详情页展示单个演员的头像、名称、扩展信息和关联影片。

关联影片使用和库页一致的影片卡网格。点击影片进入影片详情；从影片详情返回时，会回到当前演员详情页，而不是直接回到演员列表。

### 标签

标签页是全库统一标签总览。

标签类型包括：

- `类型`：标准库系统标签。
- `系列`：标准库系统标签。
- `厂商`：标准库系统标签。
- `自定义`：标准库和本地库都支持。

默认可以查看全部库范围，也可以切到单个库。MetaTube 标准库范围会显示系统标签和自定义标签；非标准本地库范围只显示自定义标签。

标签卡展示类型、标签名和影片数。点击标签进入标签详情；右键标签可搜索相关影片。

### 标签详情

标签详情页展示某个标签下的影片集合。

可以在当前标签范围内搜索、排序、分页，也可以切换范围。系统标签只适用于标准库；自定义标签允许在全部库或单库范围内查看。

影片卡右键菜单与库页保持一致，避免同一部影片在不同入口下操作不一致。

### 收藏

收藏页是收藏对象的首页，分为三类入口：

- 收藏影片。
- 收藏标签。
- 收藏演员。

收藏首页只负责分流，不承担搜索、排序和批量动作。

收藏影片页复用影片列表结构，支持搜索、排序、个人评分筛选、随机选片、批量取消收藏、批量添加自定义标签和进入影片详情。

收藏标签页复用标签卡结构，支持类型切换、排序、搜索、分页、批量取消收藏和搜索相关影片。

收藏演员页复用演员卡结构，支持搜索、筛选、分页、批量取消收藏和搜索相关影片。

## 常用工作流

### 建一个标准库并补齐资料

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `使用 MetaTube 搜刮`。
4. 添加扫描目录并保存。
5. 点击 `扫描`。
6. 扫描完成后点击 `抓取元数据`。
7. 进入单库内容页浏览影片。
8. 打开 `库健康` 查看缺资源、规则问题和失效记录。

### 建一个本地库并自己分类管理

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `本地库（不搜刮）`。
4. 添加扫描目录。
5. 按自己的分类方式添加合集目录规则。
6. 保存后点击 `刷新目录`。
7. 如需封面和预览，确认 FFmpeg 可用后点击 `生成动态封面`。

### 为影片打分并筛选

1. 从库页、收藏影片页、演员详情或标签详情进入影片详情。
2. 在详情页的个人评分处选择 1-5 星。
3. 返回列表后，已评分影片卡会显示评分 badge。
4. 在库页或收藏影片页使用个人评分筛选，查看指定评分范围。

### 给一批影片添加自定义标签

可以通过两种方式批量加标签：

- 在影片列表进入 `批量选择`，选中影片后使用批量工具条的自定义标签入口。
- 在本地库合集目录中使用 `当前目录加标签`，给当前目录范围内的影片追加同一个标签。

已拥有该标签的影片会自动跳过，不视为失败。

### 用搜索页查漏补库

1. 进入 `搜索`。
2. 选择 `VID`、`演员` 或 `Tag` 模式。
3. 输入单个查询词并搜索。
4. 查看结果卡上的本地状态。
5. 对已存在于标准库的结果，可点击 `补抓已有影片`。
6. 对未入库结果，可打开来源页确认信息后自行处理本地文件。

### 迁移用户数据

进入 `设置 -> 用户数据导入导出`。

可导出的用户数据包包含主要数据库、演员头像缓存、配置和清单信息，用于迁移或备份当前用户环境。影片原片目录、普通日志目录和大部分临时缓存不纳入整包导出。

导入时只接受软件定义的 `zip` 数据包。导入过程中应用会执行校验和替换流程，成功或警告通过提示反馈。

## 设置页

设置页按分组组织。修改普通设置后，需要点击 `保存设置` 才会落库；点击 `恢复默认` 会把当前表单恢复到默认值。

### 诊断

诊断固定放在设置页第一项，用于集中查看运行状态。

可以查看：

- Worker 是否正常。
- `.NET Runtime` 是否可用。
- 当前运行模式。
- `MetaTube / DMM / JavDB / JavBus` 搜索来源状态。
- `Minnano / Wikipedia JP` 演员资料补全来源状态。
- FFmpeg 状态。
- 预留的 AI / 能力状态。

常用动作包括 `刷新诊断`、`打开日志目录`、`重试启动`、打开相关来源或工具目录。

### 用户数据导入导出

该分组处理迁移、备份和辅助导出。

主要功能：

- 导出用户数据为单个 `zip`。
- 导入用户数据 `zip`。
- 查看 FFmpeg 当前版本和推荐版本。
- 打开 FFmpeg 下载页面。
- 打开 FFmpeg 工具目录。
- 刷新 FFmpeg 配置。
- 导出标准库 `VID` 索引 `json`。

`VID` 索引用于离线查重或离线检索某个 `VID` 是否已经入库，不是完整备份格式。

### 基本

常见设置包括：

- 当前语言。
- 调试开关。
- 主题模式。
- 关闭按钮行为。

关闭按钮行为有两种：隐藏到托盘或直接关闭程序。隐藏到托盘时，Worker 会继续运行；需要通过托盘菜单退出程序。

### 显示

显示设置影响列表页、详情页和卡片视觉。

主要设置：

- 卡片尺寸。
- 列表海报样式：横版海报或竖版海报。
- 海报页面横向来源：`poster / thumb / fanart`。
- 海报页面竖向来源：`poster / thumb / fanart`。
- 影片详情页主图来源：`poster / thumb / fanart`。
- 影片库默认排序。
- 演员页默认排序。

默认情况下，横向列表卡使用 `poster`，竖向列表卡使用 `thumb`，详情页主图使用 `poster`。如果指定资源缺失，页面会自动回退到可用图片。

### 播放器设置

播放器设置用于指定外部播放器路径，并配置未指定播放器时是否回退系统默认播放器。

`.strm` 远程 URL 的实际播放能力取决于所选播放器是否支持直接打开该 URL。

### MetaTube

MetaTube 分组保存：

- 服务地址。
- 请求超时。

标准库抓取、补资源和部分远端能力依赖 MetaTube。应用可以在未配置 MetaTube 的情况下启动，但相关能力会不可用或降级。

### 关于

关于分组展示：

- 当前版本。
- 最新 Release 版本。
- 版本检查状态。
- GitHub 仓库地址。
- 最新版本说明。
- 前往 GitHub 更新。
- 赞助入口。

版本检查失败时，不会把旧说明伪装成最新说明，可通过 GitHub Releases 查看完整发布说明。

## 排障入口

常见问题优先从这些位置排查：

| 问题 | 优先查看 |
| --- | --- |
| 应用启动失败或 Worker 异常 | `设置 -> 诊断 -> 运行时与 Worker` |
| 标准库抓取失败 | `设置 -> 诊断` 和单库 `库健康` |
| 搜索没有结果 | `设置 -> 诊断 -> 搜索来源诊断` |
| 演员年龄、身高、罩杯补不出来 | `设置 -> 诊断 -> 演员信息获取诊断` |
| 本地库封面或预览生成失败 | `设置 -> 用户数据导入导出 -> FFmpeg` 和单库 `库健康` |
| 文件没有进入标准库 | `库健康 -> 查看文件规则问题` 和 `standard-library-naming-rules.md` |
| `.strm` 没有入库或不能播放 | 检查 `.strm` 文件名、文件内容和播放器 URL 支持 |
