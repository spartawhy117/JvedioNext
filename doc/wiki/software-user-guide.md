# JvedioNext 使用指南

`JvedioNext` 是 Windows 桌面端离线影片管理工具，主要用于管理本地影片、补齐资料、维护演员和标签、查缺口，以及迁移用户数据。

它不是在线播放站，也不内置影片资源。影片文件、`.strm` 文件、播放器、`MetaTube` 服务地址和远端搜索来源都需要用户自行准备。

## 1. 快速选择库类型

新建媒体库时，先判断你要管理的资源属于哪一类。

| 你手里的资源 | 推荐库类型 | 主要用途 |
| --- | --- | --- |
| 标准 JAV 番号影片，文件名能识别 `VID` | 标准库（MetaTube） | 扫描番号、抓取元数据、补海报和演员 |
| 规范命名的 `.strm` 远程索引 | 标准库（MetaTube） | 进入海报墙、详情页和随机选片 |
| MDCX 抓取输出且有 NFO 或本地图片的影片 | MDCX 抓取目录 | 导入已有资料，不改写原目录 |
| 论坛或社区下载的国产、OF 等非标准 JAV 数据 | 本地库（不搜刮） | 保留原目录，自己做分类、合集和标签管理 |
| 散装目录、合集盘、无稳定番号资源 | 本地库（不搜刮） | 浏览、播放、生成封面预览、打自定义标签 |

简单判断：

- 想自动识别番号并抓取资料：用 `标准库`。
- 已有 MDCX 输出的 NFO、海报和演员信息：将对应目录设为 `MDCX 抓取`，再点击 `扫描`。
- 想保留原目录并按自己的分类管理：用 `本地库（不搜刮）`。

MDCX 抓取目录的扫描、抓取、演员和用户数据迁移边界见：[MDCX 兼容使用说明](https://github.com/spartawhy117/JvedioNext/blob/master/doc/wiki/mdcx-compatibility-guide.md)。

## 2. 标准库

标准库适合标准番号资源。它的主线是：`扫描 -> 抓取元数据 -> 浏览详情 -> 健康修复`。

### 2.1 新建标准库

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `使用 MetaTube 搜刮`。
4. 添加一个或多个扫描目录。
5. 保存后点击 `扫描`。
6. 扫描完成后点击 `抓取元数据`。
7. 进入单库内容页浏览影片。

### 2.2 扫描

标准库扫描会按文件名识别 `VID`，建立影片索引，并在规则允许时整理到标准库结构。

扫描后重点看：

- 成功入库数量。
- 文件规则问题数量。
- `.strm` 导入、跳过或内容无效情况。
- 多子集影片是否正确聚合。

命名不合规的文件会进入规则问题报告，不会被当成标准影片直接抓取。详细命名边界见 `standard-library-naming-rules.md`。

### 2.3 抓取元数据

抓取依赖 `MetaTube` 服务地址。

抓取会补齐：

- 标题、发布日期、时长、导演、厂商等基础信息。
- `NFO`。
- `poster / thumb / fanart`。
- 演员关系和演员头像。
- 类型、系列、厂商等系统标签。

如果抓取失败或资源缺失，进入单库 `库健康` 处理。

### 2.4 多子集影片

合法多子集影片会在列表中聚合为一张主卡，并显示 `N Parts`。

进入详情页后，再通过 `Part` 播放条选择具体子集。

### 2.5 `.strm` 文件

`.strm` 当前只适用于标准库。

最小规则：

- 文件名必须符合标准库命名规则，例如 `ABC-123.strm`、`ABC-123_2.strm`。
- 文件内容建议只保留一个绝对 `http / https` 播放地址。
- 不支持本地路径、相对路径、NAS 路径或非 `http / https` 协议。

最终能否播放取决于播放器是否支持直接打开远程 URL。

### 2.6 标准库健康

标准库健康页重点查看：

- 抓取状态。
- `NFO / poster / thumb / fanart` 缺口。
- 文件规则问题。
- 失效记录。
- 分组一致性。

常用动作：

- `刷新健康状态`：只刷新统计。
- `一键重抓并补资源`：对待修复候选执行补救性重抓。
- `重新检查失效记录`：检查数据库记录和真实文件是否一致。
- `查看文件规则问题`：打开命名规范或 `.strm` 规则报告。

## 3. 本地库

本地库适合从论坛或社区下载的国产、OF 等非标准 JAV 数据。它不追求自动搜刮标准元数据，而是保留原目录结构，让用户自己做分类、合集和自定义标签管理。

### 3.1 新建本地库

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `本地库（不搜刮）`。
4. 添加扫描目录。
5. 按自己的分类方式添加合集目录规则。
6. 如需把下一层目录也显示成子合集，勾选 `下一层子目录按合集显示`。
7. 保存后点击 `刷新目录`。
8. 如需封面和预览，确认 FFmpeg 可用后点击 `生成动态封面`。

### 3.2 刷新目录

本地库的 `刷新目录` 是同步，不是整理。

它会：

- 同步新增、删除和路径变化到软件库。
- 更新库内影片列表。
- 保留原目录、原文件和原命名。

它不会：

- 移动原文件。
- 重命名文件。
- 按 `VID` 建目录。
- 删除真实影片文件。

### 3.3 合集目录列表

`合集目录列表` 用来把某些目录显示成库里的“合集卡”。

操作方式：

1. 在 `库管理` 中点击本地库的 `编辑`，或新建本地库时打开媒体库弹窗。
2. 在扫描目录下方找到 `合集目录列表`。
3. 点击 `添加合集目录`。
4. 选择你想作为合集入口的目录，例如按来源、作者、站点或主题整理好的目录。
5. 保存后执行 `刷新目录`。

示例：

```text
国产/
  作者A/
    作品1.mp4
  作者B/
    作品2.mp4
```

如果把 `国产` 加为合集目录，库首页会显示 `国产` 合集卡。点击后进入这个分类，再继续浏览影片或子合集。

这个设置只改变软件里的浏览层级，不会创建、移动或重命名真实文件夹。

### 3.4 下一层子目录按合集显示

如果合集目录下面还有一层目录也想作为分类入口，可以勾选 `下一层子目录按合集显示`。

以上面的目录为例，进入 `国产` 合集页时会显示 `作者A`、`作者B` 子合集；进入子合集后才看到具体影片。

建议：

- 目录结构是 `分类 / 作者 / 视频`：建议勾选。
- 目录结构是 `分类 / 视频`：不需要勾选。
- 当前只展开下一层，不会无限递归。

### 3.5 生成动态封面

本地库不依赖远端海报。它通过 FFmpeg 生成：

- 静态封面。
- 悬停预览 `preview.mp4`。

生成结果缓存到软件数据目录，不写回原影片目录。

### 3.6 自定义标签管理

本地库主要依赖自定义标签做二次管理。

常用方式：

- 在影片详情页编辑单个影片标签。
- 在批量选择模式中，为选中影片追加标签。
- 在本地库合集目录中使用 `当前目录加标签`，给当前目录范围内影片追加同一个标签。

已拥有该标签的影片会自动跳过。

### 3.7 本地库健康

本地库健康页重点查看：

- 静态封面是否缺失。
- `preview.mp4` 是否缺失。
- 文件与索引摘要。
- 结构一致性。

常用动作：

- `刷新健康状态`：只刷新统计。
- `一键修复封面与预览`：补缺失静态封面和 `preview.mp4`。
- `查看文件规则问题`：查看路径或 `.strm` 规则问题。

## 4. 通用能力

| 能力 | 说明 |
| --- | --- |
| 搜索、排序、分页 | 库页、收藏页、演员详情、标签详情都支持常规结果浏览 |
| 收藏 | 支持收藏影片、标签和演员 |
| 个人评分 | 在影片详情页设置，库页和收藏影片页可筛选 |
| 资源筛选 | 标准库库页可筛选无可显示封面或缺配套资料的影片 |
| 自定义标签 | 标准库和本地库都支持，可单个编辑或批量追加 |
| 批量选择 | 进入批量模式后整卡选择，动作在顶部工具条 |
| 随机选片 | 遵守当前搜索、合集层级、评分和资源筛选 |
| 删除与移除 | `移除` 只删软件记录，危险删除会走确认弹窗 |

## 6. 设置速查

| 设置分组 | 主要内容 |
| --- | --- |
| 诊断 | Worker、`.NET Runtime`、搜索来源、演员资料来源、FFmpeg 状态 |
| 用户数据导入导出 | 导入/导出用户数据、FFmpeg 工具区、导出 `VID` 索引 |
| 基本 | 语言、调试开关、主题模式、关闭按钮行为 |
| 显示 | 卡片尺寸、海报样式、图片来源、默认排序 |
| 播放器设置 | 外部播放器路径、系统默认播放器回退 |
| MetaTube | 服务地址、请求超时 |
| 关于 | 当前版本、最新版本、GitHub Releases、使用说明、赞助入口 |

首次启动失败、抓取失败、搜索无结果、FFmpeg 不可用时，优先看 `设置 -> 诊断`。

## 7. 常用工作流

### 7.1 建标准库并补齐资料

1. 新建媒体库，选择 `使用 MetaTube 搜刮`。
2. 添加扫描目录。
3. 点击 `扫描`。
4. 点击 `抓取元数据`。
5. 进入 `库健康` 查看缺资源和规则问题。

### 7.2 建本地库并按目录分类

1. 新建媒体库，选择 `本地库（不搜刮）`。
2. 添加扫描目录。
3. 添加合集目录规则。
4. 按目录结构决定是否勾选 `下一层子目录按合集显示`。
5. 点击 `刷新目录`。
6. 如需封面预览，点击 `生成动态封面`。

### 7.3 用标签管理本地库

1. 进入本地库内容页。
2. 进入对应合集或目录。
3. 点击 `当前目录加标签`。
4. 输入一个自定义标签，或选择历史标签。
5. 进入 `标签 -> 自定义` 查看聚合结果。

### 7.4 查漏补库

1. 进入 `搜索`。
2. 选择 `VID`、`演员` 或 `Tag` 模式。
3. 输入单个查询词。
4. 查看结果卡上的本地状态。
5. 已存在于标准库的结果可点击 `补抓已有影片`。

### 7.5 迁移用户数据

进入 `设置 -> 用户数据导入导出`。

用户数据导出会打包主要数据库、演员头像缓存、配置和清单信息。影片原片目录、普通日志目录和大部分临时缓存不纳入整包导出。

## 8. 排障

| 问题 | 优先查看 |
| --- | --- |
| 应用启动失败或 Worker 异常 | `设置 -> 诊断 -> 运行时与 Worker` |
| 标准库抓取失败 | `设置 -> 诊断` 和单库 `库健康` |
| 搜索没有结果 | `设置 -> 诊断 -> 搜索来源诊断` |
| 演员年龄、身高、罩杯补不出来 | `设置 -> 诊断 -> 演员信息获取诊断` |
| 本地库封面或预览生成失败 | `设置 -> 用户数据导入导出 -> FFmpeg` 和单库 `库健康` |
| 本地库合集入口没有显示 | 检查 `合集目录列表`，保存后执行 `刷新目录` |
| 本地库子目录没有显示成子合集 | 检查是否勾选 `下一层子目录按合集显示` |
| 文件没有进入标准库 | `库健康 -> 查看文件规则问题` 和 `standard-library-naming-rules.md` |
| `.strm` 没有入库或不能播放 | 检查 `.strm` 文件名、文件内容和播放器 URL 支持 |
