# JvedioNext 使用指南

本文面向最终用户，按“先理解两类库，再了解页面”的顺序介绍 `JvedioNext`。如果你只想快速开始，先判断自己应该建 `标准库` 还是 `本地库（不搜刮）`，再按对应章节操作。

## 1. 软件能解决什么问题

`JvedioNext` 是 Windows 桌面端离线影片管理工具，重点解决本地资源越来越多以后如何整理、补资料、查缺口、维护演员和标签、迁移用户数据。

它不是在线播放站，也不内置影片资源。影片文件、`.strm` 文件、播放器、`MetaTube` 服务地址和远端搜索来源都需要用户自行准备。

常见使用场景：

- 管理按标准番号命名的 JAV 资源，并补齐 `NFO`、海报、演员、标签和详情。
- 管理从论坛或社区下载的国产、OF 等非标准 JAV 数据，保留原目录结构，按自己的分类、合集和标签管理。
- 管理规范命名的 `.strm` 远程索引，让它们进入海报墙、详情页和随机选片链路。
- 通过演员、标签、收藏、评分和搜索查找资源。
- 迁移或备份自己的媒体库、配置、封面缓存和演员资料。

## 2. 先选择你的库类型

新建或编辑媒体库时，需要选择元数据来源。当前主要分为两类：`使用 MetaTube 搜刮` 和 `本地库（不搜刮）`。

| 对比项 | 标准库（MetaTube） | 本地库（不搜刮） |
| --- | --- | --- |
| 适合内容 | 规范番号影片、规范命名 `.strm` | 论坛或社区下载的国产、OF 等非标准 JAV 数据 |
| 核心目标 | 自动识别番号并抓取标准元数据 | 保留原目录，自己做分类、合集和标签管理 |
| 是否需要 MetaTube | 需要，抓取和补资料依赖它 | 不需要 |
| 是否改造目录 | 可按标准库规则整理到 `VID` 目录 | 不移动、不重命名、不建 `VID` 目录 |
| 页面主流程 | 海报卡 -> 影片详情页 | 合集/影片浏览 -> 本地影片直接播放 |
| 图片与资料 | 抓取 `NFO / poster / thumb / fanart` | FFmpeg 生成静态封面和 `preview.mp4` |
| 标签能力 | 系统标签 + 自定义标签 | 自定义标签 |
| 健康页重点 | 抓取状态、资源缺口、规则问题、失效记录、分组一致性 | 静态封面、预览、文件索引、结构一致性 |

一句话选择：

- 文件名能按番号规则识别，想要抓取元数据：建 `标准库`。
- 文件名和来源不适合标准搜刮，想按自己的目录和标签管理：建 `本地库（不搜刮）`。

## 3. 标准库使用指南

### 3.1 适合什么资源

标准库适合按番号管理的影片目录，包括常见标准番号、当前支持的素人番号、部分明确厂商或来源信号的无码番号，以及规范命名的 `.strm` 文件。

标准库不适合用来管理完全非规则命名的国产、OF 或论坛合集资源。这些内容即使能放进扫描目录，也可能因为没有稳定 `VID` 无法进入标准抓取链路。

### 3.2 新建标准库

典型流程：

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `使用 MetaTube 搜刮`。
4. 添加一个或多个扫描目录。
5. 保存后点击 `扫描`。
6. 扫描完成后点击 `抓取元数据`。
7. 进入单库内容页浏览影片。
8. 打开 `库健康` 查看缺资源、规则问题和失效记录。

### 3.3 标准库命名要求

标准库按文件名识别影片，不靠目录名或远程链接猜测身份。

基本规则：

- 文件名应包含可识别的标准 `VID`。
- 无码样本需要能从文件名识别厂商、来源或已登记系列号，才会进入标准库抓取主链。
- 不支持的命名会进入规则问题报告，不会被当成标准影片直接抓取。
- 更细的规则请看 `standard-library-naming-rules.md`。

### 3.4 扫描

标准库扫描负责识别影片、建立索引，并在规则允许时整理到标准库结构。

扫描后你会看到：

- 已扫描影片数量。
- 文件规则问题数量。
- `.strm` 导入、跳过或内容无效情况。
- 多子集影片的聚合结果。

扫描阶段不会因为普通扫描自动删除用户磁盘上的原影片文件。

### 3.5 抓取元数据

标准库抓取依赖 `MetaTube` 服务地址。

抓取会尝试补齐：

- 标题、发布日期、时长、导演、厂商等基础信息。
- `NFO`。
- `poster / thumb / fanart`。
- 演员关系和演员头像。
- 系统标签：类型、系列、厂商。

如果抓取失败或资源缺失，可以从单库 `库健康` 里查看问题并触发修复性重抓。

### 3.6 影片详情、演员和标签

标准库影片点击卡片后进入影片详情页。

详情页可以：

- 播放影片。
- 收藏影片。
- 设置个人五星评分。
- 查看和编辑自定义标签。
- 查看类型、系列、厂商等系统标签。
- 进入演员详情。
- 对演员或标签右键 `搜索相关影片`。
- 查看清晰图片。
- 打开所在文件夹。
- 重新抓取当前影片元数据。

### 3.7 多子集影片

合法多子集影片会在列表中聚合为一张主卡。

例如同一影片存在 `ABC-123.mp4`、`ABC-123_2.mp4` 或 `ABC-123 CD1.mp4`、`ABC-123 CD2.mp4` 时，列表页会显示一张主卡，并用 `N Parts` 标记存在多个子集。进入详情页后，再通过 `Part` 播放条选择具体子集。

### 3.8 `.strm` 文件

`.strm` 当前只适用于标准库。

最小规则：

- 文件名必须符合标准库命名规则，例如 `ABC-123.strm`、`ABC-123_2.strm`、`FC2-PPV-4880000.strm`。
- 文件内容建议只保留一个绝对 `http / https` 播放地址。
- 不支持用 `.strm` 包装本地路径、相对路径、NAS 路径或非 `http / https` 协议。

符合规则的 `.strm` 会像普通标准库影片一样进入扫描、海报墙、详情页和随机选片链路。最终能否播放取决于播放器是否支持直接打开远程 URL。

### 3.9 库健康与补资源

标准库健康页用于判断当前库是否完整、可信、可维护。

重点查看：

- 抓取状态。
- `NFO / poster / thumb / fanart` 缺口。
- 文件规则问题。
- 失效记录。
- 分组一致性。

常用动作：

- `刷新健康状态`：只刷新统计，不触发修复。
- `一键重抓并补资源`：对待修复候选执行补救性重抓。
- `重新检查失效记录`：重新检查数据库记录和真实文件是否一致。
- `查看文件规则问题`：打开命名规范或 `.strm` 规则问题报告。

### 3.10 标准库常见问题

| 问题 | 优先查看 |
| --- | --- |
| 文件没有进入标准库 | `库健康 -> 查看文件规则问题` 和 `standard-library-naming-rules.md` |
| 抓取失败 | `设置 -> 诊断` 和单库 `库健康` |
| 海报或 NFO 缺失 | `库健康 -> 一键重抓并补资源` |
| `.strm` 没有入库 | 检查文件名是否符合标准库规则、内容是否为绝对 `http / https` 地址 |
| `.strm` 不能播放 | 检查远程地址是否有效，以及播放器是否支持直接打开 URL |

## 4. 本地库使用指南

### 4.1 适合什么资源

本地库适合从论坛或社区下载的国产、OF 等非标准 JAV 电影数据。这类资源通常没有稳定番号、没有可直接搜刮的标准元数据，用户更需要保留原目录结构，并按自己的分类、合集和自定义标签进行管理。

本地库的目标不是“自动识别番号并搜刮”，而是把用户已有目录变成更好浏览、筛选、收藏和打标签的本地资料库。

### 4.2 新建本地库

典型流程：

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `本地库（不搜刮）`。
4. 添加扫描目录。
5. 按自己的分类方式添加合集目录规则。
6. 如需把下一层目录也显示成子合集，勾选 `下一层子目录按合集显示`。
7. 保存后点击 `刷新目录`。
8. 如需封面和预览，确认 FFmpeg 可用后点击 `生成动态封面`。

### 4.3 刷新目录

本地库的 `刷新目录` 是同步，不是整理。

它会：

- 同步新增、删除和路径变化到软件库。
- 更新库内影片列表。
- 保留用户原目录、原文件和原命名。

它不会：

- 移动原文件。
- 重命名文件。
- 按 `VID` 建目录。
- 因为目录名像番号就改造成标准库结构。
- 删除真实影片文件。

### 4.4 合集目录列表

`合集目录列表` 用来把某些目录显示成库里的“合集卡”。

操作方式：

1. 在 `库管理` 中点击本地库的 `编辑`，或新建本地库时打开媒体库弹窗。
2. 在扫描目录下方找到 `合集目录列表`。
3. 点击 `添加合集目录`。
4. 选择你想作为合集入口的目录，例如按来源、作者、站点或主题整理好的目录。
5. 保存后执行 `刷新目录`。

作用示例：

```text
国产/
  作者A/
    作品1.mp4
  作者B/
    作品2.mp4
```

如果把 `国产` 加为合集目录，库首页会显示 `国产` 合集卡。点击 `国产` 后，可以进入这个分类下继续浏览影片或子合集。

这个设置只影响软件里的浏览层级，不会创建、移动或重命名真实文件夹。

### 4.5 下一层子目录按合集显示

如果合集目录下面还有一层你想继续作为分类的子目录，可以勾选 `下一层子目录按合集显示`。

以上面的目录为例，勾选后进入 `国产` 合集页时，会看到 `作者A`、`作者B` 这类子合集入口；再进入子合集后才看到具体影片。

使用建议：

- 如果你的目录结构是 `分类 / 作者 / 视频`，建议勾选。
- 如果你的目录结构是 `分类 / 视频`，不需要勾选。
- 当前只把下一层目录显示为子合集，不会无限递归展开更多层级。

### 4.6 生成动态封面

本地库不依赖 `NFO` 和远端海报。它通过 FFmpeg 生成：

- 静态封面。
- 悬停预览 `preview.mp4`。

生成结果缓存到软件数据目录，不写回原影片目录。

如果封面或预览缺失，优先检查：

- `设置 -> 用户数据导入导出 -> FFmpeg` 是否识别到可用版本。
- 单库 `库健康 -> 一键修复封面与预览`。

### 4.7 自定义标签管理

本地库主要依赖自定义标签来做二次管理。

你可以：

- 在影片详情页编辑单个影片的自定义标签。
- 在批量选择模式中，为选中影片追加自定义标签。
- 在本地库合集目录中使用 `当前目录加标签`，给当前目录范围内的影片追加同一个标签。

已拥有该标签的影片会自动跳过，不视为失败。

### 4.8 本地库播放逻辑

本地库影片卡点击后直接调用播放器播放，不进入标准库那种完整影片详情页。

原因是本地库通常没有稳定的标准元数据和系统标签，重点是快速浏览、预览、播放和自定义标签管理。

### 4.9 库健康与封面预览修复

本地库健康页重点查看：

- 静态封面是否缺失。
- `preview.mp4` 是否缺失。
- 文件与索引摘要。
- 结构一致性。

常用动作：

- `刷新健康状态`：只刷新统计。
- `一键修复封面与预览`：补缺失静态封面和 `preview.mp4`。
- `查看文件规则问题`：查看 `.strm` 或路径规则问题。

### 4.10 本地库常见问题

| 问题 | 优先查看 |
| --- | --- |
| 合集入口没有显示 | 检查是否在 `合集目录列表` 中添加了正确目录，并执行 `刷新目录` |
| 子目录没有显示成子合集 | 检查是否勾选 `下一层子目录按合集显示` |
| 本地影片没有封面或预览 | 检查 FFmpeg，并进入 `库健康 -> 一键修复封面与预览` |
| 删除库后原文件还在 | 本地库默认只移除软件内引用，不删除真实原文件 |
| 自定义标签没有更新 | 确认保存成功后刷新当前列表或标签页 |

## 5. 两类库都支持的通用能力

### 5.1 搜索、排序和分页

库页、收藏影片、演员详情和标签详情都使用相近的结果页结构，支持搜索、排序、分页和返回状态恢复。

页面会尽量记住当前搜索条件、排序、分页和来源上下文。进入详情页再返回时，通常会回到原来的位置。

### 5.2 收藏

收藏支持三类对象：

- 影片。
- 标签。
- 演员。

收藏首页只负责分流。进入收藏影片、收藏标签或收藏演员后，再进行搜索、筛选、分页和批量操作。

### 5.3 个人评分

影片详情页支持个人五星评分。

评分只写入本地数据库，不覆盖搜刮站点评分，也不会首版写入 `NFO`。库页和收藏影片页可以按个人评分筛选，已评分影片卡会显示评分 badge。

### 5.4 自定义标签

自定义标签同时支持标准库和本地库。

常用入口：

- 影片详情页编辑单个影片标签。
- 影片列表批量选择后批量追加标签。
- 本地库当前目录范围追加标签。
- 标签页查看 `自定义` 类型。
- 标签详情页查看某个自定义标签下的影片。

### 5.5 批量选择和批量操作

影片、标签、演员相关页面都支持批量选择。

进入批量模式后：

- 点击整张卡片会切换选中状态。
- 卡片不会再进入详情、播放或下钻。
- 至少选中 1 项后显示批量工具条。
- 批量动作通常只作用于当前页或当前选择，不跨页隐式操作。

### 5.6 随机选片

标准库、本地库和收藏影片页支持随机选片。

随机选片会遵守当前筛选范围，例如当前关键字、合集层级或个人评分筛选。命中后进入影片详情或对应播放链路。

### 5.7 删除、移除和文件安全边界

需要区分两种语义：

- `移除`：只移除软件内记录或引用，不删除真实影片文件。
- `删除影片和数据`：删除影片文件与软件数据，但仍会通过确认弹窗提醒影响范围。

对 `.strm` 条目，删除的是本地 `.strm` 引用文件，不影响远程地址对应的真实资源。

## 6. 页面说明

### 6.1 库管理

`库管理` 是媒体库管理首页，不展示影片列表。

主要能力：

- 新建媒体库。
- 点击库名进入单库内容页。
- 标准库执行 `扫描`、`抓取元数据`。
- 本地库执行 `刷新目录`、`生成动态封面`。
- 编辑库名、扫描目录和合集规则。
- 移除库或删除库和库内影片。
- 进入 `查看健康`。

### 6.2 单库内容页

单库内容页用于浏览某一个媒体库中的内容。

标准库中，影片以统一海报卡展示，点击进入影片详情页。

本地库中，页面可能同时展示 `合集入口` 和 `影片`。`合集入口` 来自建库或编辑库时配置的合集目录规则，用来把某些目录显示成可点击的分类卡。点击合集进入下一层；点击本地影片直接调用播放器播放。

### 6.3 影片详情

影片详情页展示单部影片信息。

主要能力：

- 查看标题、主图、`VID`、发布日期、时长、导演和 sidecar 状态。
- 播放影片或选择多子集 `Part` 播放。
- 设置或清除个人五星评分。
- 收藏影片。
- 重新抓取当前影片元数据。
- 查看清晰图片。
- 打开所在文件夹。
- 查看演员并进入演员详情。
- 查看和编辑自定义标签。
- 从演员或标签右键跳转到搜索页。

从列表进入详情时，如果来源列表提供上下文，详情页会显示上一部和下一部按钮，只在当前来源页序列内切换。

### 6.4 库健康

`库健康` 用来判断单个媒体库是否完整、可信、可维护。

标准库显示抓取和资源修复，本地库显示封面与预览修复。健康页不会因为打开页面就自动扫描、抓取或清理；只有点击明确动作才会触发后台任务。

### 6.5 搜索

搜索页用于远端搜索和本地状态核实，不是页内详情浏览器。

支持三种模式：

- 单个 `VID`。
- 单个演员原词。
- 单个 `Tag` 原词。

搜索结果会显示远端影片卡，并回填本地状态。标准库已存在的结果可以触发 `补抓已有影片`；所有结果都可以打开来源页或更多来源。

### 6.6 演员

演员页是跨库演员聚合入口。

主要能力：

- 搜索演员。
- 按名称或作品数排序。
- 按作品数量、头像状态、年龄、身高、罩杯筛选。
- 批量收藏或批量取消收藏。
- 批量补全演员扩展信息。
- 右键演员搜索相关影片。
- 进入演员详情页。

演员详情页展示头像、名称、扩展信息和关联影片。点击关联影片进入影片详情页。

### 6.7 标签

标签页是全库统一标签总览。

标签类型包括：

- `类型`：标准库系统标签。
- `系列`：标准库系统标签。
- `厂商`：标准库系统标签。
- `自定义`：标准库和本地库都支持。

默认可以查看全部库范围，也可以切到单个库。MetaTube 标准库范围会显示系统标签和自定义标签；非标准本地库范围只显示自定义标签。

### 6.8 收藏

收藏页分为三类入口：

- 收藏影片。
- 收藏标签。
- 收藏演员。

收藏影片页支持搜索、排序、个人评分筛选、随机选片、批量取消收藏、批量添加自定义标签和进入影片详情。

收藏标签页支持类型切换、排序、搜索、分页、批量取消收藏和搜索相关影片。

收藏演员页支持搜索、筛选、分页、批量取消收藏和搜索相关影片。

### 6.9 设置

设置页集中管理运行环境、显示、播放器、MetaTube、用户数据和诊断能力。详细说明见下一章。

## 7. 设置页

设置页按分组组织。修改普通设置后，需要点击 `保存设置` 才会落库；点击 `恢复默认` 会把当前表单恢复到默认值。

### 7.1 诊断

诊断固定放在设置页第一项，用于集中查看运行状态。

可以查看：

- Worker 是否正常。
- `.NET Runtime` 是否可用。
- 当前运行模式。
- `MetaTube / DMM / JavDB / JavBus` 搜索来源状态。
- `Minnano / Wikipedia JP` 演员资料补全来源状态。
- FFmpeg 状态。
- 预留的 AI / 能力状态。

### 7.2 用户数据导入导出

该分组处理迁移、备份和辅助导出。

主要功能：

- 导出用户数据为单个 `zip`。
- 导入用户数据 `zip`。
- 查看 FFmpeg 当前版本和推荐版本。
- 打开 FFmpeg 下载页面。
- 打开 FFmpeg 工具目录。
- 刷新 FFmpeg 配置。
- 导出标准库 `VID` 索引 `json`。

`VID` 索引用于离线查重或离线检索某个 `VID` 是否已经入库，不是完整备份格式。

### 7.3 基本

常见设置包括：

- 当前语言。
- 调试开关。
- 主题模式。
- 关闭按钮行为。

关闭按钮行为有两种：隐藏到托盘或直接关闭程序。隐藏到托盘时，Worker 会继续运行；需要通过托盘菜单退出程序。

### 7.4 显示

显示设置影响列表页、详情页和卡片视觉。

主要设置：

- 卡片尺寸。
- 列表海报样式：横版海报或竖版海报。
- 海报页面横向来源：`poster / thumb / fanart`。
- 海报页面竖向来源：`poster / thumb / fanart`。
- 影片详情页主图来源：`poster / thumb / fanart`。
- 影片库默认排序。
- 演员页默认排序。

默认情况下，横向列表卡使用 `poster`，竖向列表卡使用 `thumb`，详情页主图使用 `poster`。如果指定资源缺失，页面会自动回退到可用图片。

### 7.5 播放器设置

播放器设置用于指定外部播放器路径，并配置未指定播放器时是否回退系统默认播放器。

`.strm` 远程 URL 的实际播放能力取决于所选播放器是否支持直接打开该 URL。

### 7.6 MetaTube

MetaTube 分组保存：

- 服务地址。
- 请求超时。

标准库抓取、补资源和部分远端能力依赖 MetaTube。应用可以在未配置 MetaTube 的情况下启动，但相关能力会不可用或降级。

### 7.7 关于

关于分组展示：

- 当前版本。
- 最新 Release 版本。
- 版本检查状态。
- GitHub 仓库地址。
- 最新版本说明。
- 前往 GitHub 更新。
- 赞助入口。

版本检查失败时，不会把旧说明伪装成最新说明，可通过 GitHub Releases 查看完整发布说明。

## 8. 常用工作流

### 8.1 建标准库并补齐资料

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `使用 MetaTube 搜刮`。
4. 添加扫描目录并保存。
5. 点击 `扫描`。
6. 扫描完成后点击 `抓取元数据`。
7. 进入单库内容页浏览影片。
8. 打开 `库健康` 查看缺资源、规则问题和失效记录。

### 8.2 建本地库并按目录分类

1. 进入 `库管理`。
2. 点击 `新建媒体库`。
3. 选择 `本地库（不搜刮）`。
4. 添加扫描目录。
5. 按自己的分类方式添加合集目录规则。
6. 如需把下一层目录也显示成子合集，勾选 `下一层子目录按合集显示`。
7. 保存后点击 `刷新目录`。
8. 如需封面和预览，确认 FFmpeg 可用后点击 `生成动态封面`。

### 8.3 用标签管理本地库

1. 进入本地库内容页。
2. 进入对应合集或目录。
3. 点击 `当前目录加标签`。
4. 输入一个自定义标签，或选择历史标签。
5. 确认后，当前目录范围内影片会追加该标签。
6. 进入 `标签 -> 自定义` 查看标签聚合结果。

### 8.4 查漏补库

1. 进入 `搜索`。
2. 选择 `VID`、`演员` 或 `Tag` 模式。
3. 输入单个查询词并搜索。
4. 查看结果卡上的本地状态。
5. 对已存在于标准库的结果，可点击 `补抓已有影片`。
6. 对未入库结果，可打开来源页确认信息后自行处理本地文件。

### 8.5 迁移用户数据

进入 `设置 -> 用户数据导入导出`。

可导出的用户数据包包含主要数据库、演员头像缓存、配置和清单信息，用于迁移或备份当前用户环境。影片原片目录、普通日志目录和大部分临时缓存不纳入整包导出。

导入时只接受软件定义的 `zip` 数据包。导入过程中应用会执行校验和替换流程，成功或警告通过提示反馈。

## 9. 排障入口

| 问题 | 优先查看 |
| --- | --- |
| 应用启动失败或 Worker 异常 | `设置 -> 诊断 -> 运行时与 Worker` |
| 标准库抓取失败 | `设置 -> 诊断` 和单库 `库健康` |
| 搜索没有结果 | `设置 -> 诊断 -> 搜索来源诊断` |
| 演员年龄、身高、罩杯补不出来 | `设置 -> 诊断 -> 演员信息获取诊断` |
| 本地库封面或预览生成失败 | `设置 -> 用户数据导入导出 -> FFmpeg` 和单库 `库健康` |
| 本地库合集入口没有显示 | 检查 `合集目录列表`，保存后执行 `刷新目录` |
| 本地库子目录没有显示成子合集 | 检查是否勾选 `下一层子目录按合集显示` |
| 文件没有进入标准库 | `库健康 -> 查看文件规则问题` 和 `standard-library-naming-rules.md` |
| `.strm` 没有入库或不能播放 | 检查 `.strm` 文件名、文件内容和播放器 URL 支持 |
