# STRM 文件写法

`.strm` 文件只在使用 MetaTube 的标准库中导入。它是本地保存的远程播放引用，不是远端媒体本身。

## 文件要求

- 文件名必须符合标准库 VID 命名，例如 `ABC-123.strm` 或 `ABC-123_2.strm`。
- 内容从上到下读取第一个非空、非注释的目标行；`#`、`//`、`;` 开头的行是注释。
- 目标必须是绝对 `http://` 或 `https://` 地址。一个文件只使用第一个目标，不是播放列表。

## 导入与播放

- 合法文件会作为远程索引进入海报墙和详情页，卡片显示 `STRM`。
- 播放交给已配置的播放器或系统默认播放器；Jvedio 只检查本地文件、地址格式和播放器配置，不保证远端地址可播放。
- 删除影片时删除本地 `.strm` 引用和本地数据，不影响远端地址指向的媒体。

## 不支持与排障

- 不支持本地路径、网络共享、磁力链、非 HTTP(S) 协议和多地址列表。
- 空文件、只有注释或无效目标会被扫描跳过并记录规则问题。
- 非标准本地库不会导入 `.strm`。请先确认文件名、首个目标行和播放器是否支持远程 URL；目录组织与合集浏览请参考 [《软件使用指南》](software-user-guide.md#33-按目录浏览合集)。

工程实现、sidecar、扫描和删除合同见 [STRM 支持设计](../modules/20-strm-support-design.md)。
